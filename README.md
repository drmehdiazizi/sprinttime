## 🏃 What is SprintTime?

SprintTime is a **sprint timer and running video analysis app** designed for sprinters, track and field athletes, running coaches, trainers, and anyone who wants to analyze sprint performance using video.

Instead of relying only on a traditional stopwatch, SprintTime lets you use a recorded running video to identify the start and finish moments of a sprint and calculate the elapsed time.

The app provides **frame-by-frame video navigation**, allowing you to inspect a sprint video closely and select precise timing points.

SprintTime can be used for **100m sprint timing, 200m sprint timing, short-distance sprint analysis, acceleration analysis, reaction time measurement, and general running performance analysis**.
